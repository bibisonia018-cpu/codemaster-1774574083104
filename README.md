# 🔒 دردشة سرية مشفرة (End-to-End Encrypted Secret Chat)

تطبيق دردشة آمن ومباشر يضمن سرية الرسائل التامة بين طرفين أو أكثر. يتم تشفير جميع الرسائل في المتصفح باستخدام `crypto-js` ولا يتم تخزينها في قاعدة البيانات إلا كنصوص مشفرة لا يمكن لأحد قراءتها بدون "مفتاح التشفير" السري.

## ✨ المميزات
* **تشفير من طرف إلى طرف (E2EE)**: الخصوصية 100٪.
* **مزامنة فورية (Real-time)**: وصول الرسائل لحظياً بين الأطراف المتصلة بنفس الغرفة.
* **وصول مضمون**: إذا كان أحد الطرفين غير متصل، سيجد الرسائل المشفرة بانتظاره عند دخوله وإدخاله لمفتاح التشفير.
* **واجهة عربية**: تصميم عصري يدعم اللغة العربية بشكل كامل باستخدام Tailwind CSS.
